# packages/domain/AGENTS.md

适用范围：`packages/domain/**`。这里是最内层领域语言，不是应用服务或工具箱。

## 允许

- 领域 ID、值对象、只读数据结构和状态联合类型；
- 不依赖外部状态的校验函数与基础不变量；
- 为序列化和跨边界表达服务的明确类型。

## 禁止

- 导入仓库内其他包、Node.js 内置模块或第三方库；
- 数据库、网络、文件系统、进程、Runtime 或模型调用；
- `Date.now()`、随机 ID、环境变量和全局可变状态；
- 把工作流、Repository、Service 或 Pi 事件塞入领域类型；
- 为方便某个 Adapter 而泄漏其字段和命名。

## 建模规则

- ID 在边界生成，领域层只校验和区分类型。
- 时间使用显式 ISO 时间或领域值，由调用方传入。
- 状态使用穷尽的字符串联合类型；Bootstrap 阶段不引入 enum、装饰器和运行时反射。
- 对象默认只读、可序列化；不要用隐藏状态的 class 表达简单事实。
- Scope、生命周期和证据语义必须能被测试，不依赖注释约定。
- 新增核心对象、状态或转换含义时，同步检查 `docs/architecture/domain-model.md`。

## 测试

至少覆盖：

- 合法边界值；
- 空值、非法值和越界值；
- 状态集合的穷尽性；
- 作用域身份不会因字符串巧合混淆；
- 序列化前后保留领域语义。
