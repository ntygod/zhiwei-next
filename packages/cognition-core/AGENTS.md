# packages/cognition-core/AGENTS.md

适用范围：`packages/cognition-core/**`。本包实现纯认知状态转换，不负责存储、Runtime 或模型调用。

## 边界

- 只能依赖 `domain`。
- 不访问数据库、网络、文件、进程、环境变量或系统时间。
- 不导入 Pi、协议 DTO、应用层或持久化实现。
- 所有时间、ID、证据和输入状态由调用方显式提供。

## 认知不变量

- LLM/Agent 推断默认只能产生 `MemoryCandidate`，不能直接成为长期 Claim。
- 接受 Candidate 前必须验证证据、来源、作用域和置信度。
- 用户明确纠正创建新 Claim，旧 Claim 进入 `superseded`；不得原地覆盖。
- 不静默选择冲突事实，也不因文本更长或模型更自信而自动覆盖用户明确输入。
- 失败、取消和 Agent 自述成功都不能自动形成成功 Outcome 或 Procedure。
- 返回新状态而不是就地修改输入对象；状态转换应可重复测试。

## 当前范围

在记忆里程碑到来前，本包中的 Claim 代码只承担架构不变量哨兵。不要在当前 Observation 里程碑中顺手加入自动提取、冲突裁决、遗忘、Procedure 或主动智能。

## 测试

每个状态转换至少覆盖：

- 成功路径；
- 前置状态不合法；
- 缺少证据或非法置信度；
- 输入对象未被修改；
- 作用域不能在纠正中漂移；
- 时间边界和版本关系正确。
