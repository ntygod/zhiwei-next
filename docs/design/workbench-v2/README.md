## 打开与体验

在现代浏览器直接打开本目录 `index.html`（无需服务、安装或构建）。使用本地外部 classic scripts，支持 file URL；所有资源随目录提供，无外部字体/图像/CDN。CSP 禁止连接、表单发送、对象与外部资源。

1. 今天 → 继续这项工作 → 检查产物与依据：结果有草稿，但缺报价与场地回执。
2. 预算变了，纠正记忆 → 预览影响 → 取消或确认 10 万 → 8 万。
3. 查阅旧方案“陈旧”和记忆“已替代”；只对本项目生效。
4. 使用当前依据开启新尝试 → 中断或模拟执行结束 → 新结果仍待核验。
5. 反馈“符合要求”不等于验证通过；不自动形成成功经验。
6. 设置 → 清除演示状态；取消不改变状态，确认回到初始内容。

顶部状态选择器提供空、加载、断线、错误、权限、模型不可用、索引滞后、副作用未知、冲突样例。选择器只改变展示情景；没有真实断线、授权或外发。浏览器前进/后退切换页面，页面内存保留；刷新完全重置。

## 设计边界

- 所有输入、金额、来源、任务、状态均合成；不输入真实数据。
- 没有 API、Runtime、模型、账户、凭据、真实授权、持久存储、遥测或后台任务。
- `model.js` 是可测试的原型交互状态，不是生产领域实现；不能作为业务真源或正式接线的替代。
- 模拟预算确认、执行结束与用户反馈都不证明 Outcome 成功。此版本无任何“已验证成功”转移。
- 不自动学习、不写生产记忆、不宣称完整权限/删除/恢复行为实现。
- P0-01 前置和受限实验状态不变；该原型不运行或替代旧安全实验。
