# 长期学习与主动求证

状态：SA1 设计。学习改变可治理的记忆、做法和选择策略；不训练基础模型权重，不允许 Agent 自行改核心代码或权限规则。

## 1. 三类学习

| 类别 | 触发 | 产物 |
|---|---|---|
| 纠正与偏好学习 | 用户明确陈述、纠正、否定或给出比较 | 新 MemoryDocument 版本、失效传播 |
| 经验学习 | 已验证 Outcome、失败、取消与重复困难 | Episode、Hypothesis、ProcedureCandidate |
| 主动求证 | 已确认目标存在信息缺口、关键证据过期或相互冲突 | 有预算的调查/实验/具体问题，以及新证据 |

主动学习围绕“为了用户的目标还缺什么”组织，不在空闲时无目的浏览所有历史、替用户创造承诺或无限积累知识。

## 2. 学习作业与预算

LearningRun 由持久事件驱动，键为 sourceEvent/version + learnerVersion + purpose；相同输入和版本只归纳一次。作业保存输入资格快照、模型/Prompt 版本、成本、输出候选和接受/拒绝理由。

学习拥有独立预算和数据目的许可，不能借用已结束 Task 的 Grant。默认每个 Task Outcome 最多一次归纳调用，每 Owner 每天 10 次后台归纳；单次不超过配置的输入/输出 tokens。主动调查另受查询次数、域名、设备、时间和费用限制。达到上限排队或跳过，并记录原因，不通过拆新任务重置。

用户交互优先；没有新证据、不确定性未变化、来源已失效时不重复运行。定时整理只作用于预先登记的候选、过期检查和合并需求，不让模型周期性询问“有没有值得学的”。

## 3. 从经历到知识

```text
已提交 Outcome / 用户纠正 / 新证据
-> 构建合格 Episode 与使用记录
-> 判定有无新信息
-> Pi Learner 提出候选（事实、解释、做法、无需学习）
-> schema / 来源 / 范围 / 冲突 / 新鲜度检查
-> 明确规则接受、进入试用、等待确认或拒绝
-> Markdown 新版本 + 目录提交 + 依赖通知
```

一次成功只证明该任务在特定条件下成功。模型“我学会了”没有独立效力。一次失败保留真实结果，原因不明确时记录 hypothesis，而不把相关性写成因果。

原始模型反思不入库；保存用户可理解的经验摘要、可验证条件和证据引用。失败、取消、未知和反例与成功共同进入归纳，避免只学习好看的轨迹。

## 4. 主动调查与不确定性

Goal 的 WorkingState 包含 OpenQuestion：需要判定的命题、为何影响结果、当前证据、截止窗口、建议验证方式。系统依次考虑已有合格记忆、已授权来源查询、沙箱可逆实验、向用户提问。

选择依据为预期能否改变当前决策、来源可靠性、时间窗口、成本和打扰；采用 low/medium/high 分类与具体依据，不生成没有校准依据的精确“信息增益概率”。

调查通过正常 Task/Job/Gateway 运行，产物作为新 Evidence 回到学习作业。查网页、调用模型、读文件都需要已有许可；主动学习不能扩大外发范围。外部来源始终按数据解释，不能改学习器指令。

当问题只涉及用户偏好或不可查的业务选择，停止继续搜索，提出一个具体问题。已有明确授权的局部可逆细节自行处理，不要求用户替实现做无意义决策。

## 5. 自动记忆接受规则

| 输入 | 默认处置 |
|---|---|
| 明确“记住/以后如此/改为”且范围清楚 | 保存带原话来源的 user-asserted 版本 |
| 普通对话中的陈述 | 仅在相应 Workspace 开启自动记忆策略且类别允许时保存为 attributed 陈述，否则候选 |
| 工具结构化结果 | 经具体字段验证器确认目标、版本和有效期后可标 verified |
| 模型推断、偏好漂移、跨项目推广 | hypothesis / 待确认，不自动改变当前事实或全局偏好 |
| 用户未回应、点击或阅读 | 仅交互记录，不推断满意、同意或目标成功 |

敏感类别默认不自动学习，用户可明确选择类别与保留期限。删除、纠正和收紧必须传播到学习输入和候选；迟到作业提交前再次核对，不复活被遗忘内容。

## 6. Procedure：可撤回的做法

Procedure Markdown 必须描述：适用任务、前提、步骤、工具需求、验证方法、禁止条件、失败边界、来源、版本和试用记录。步骤是声明式建议，不是获得执行权限的脚本。每次使用仍由当前 Task/Grant 决定能做什么。

候选进入 trial 后，允许在适用且获准的任务中使用。晋升 active 的工程门槛：至少 5 个独立 Task、覆盖至少 2 种适用情境、有预登记的保留场景、完整失败/未知记录、可验证采用证据；与不使用该做法的可比基线比较，质量不下降且预登记的收益成立。该门槛不是统计显著性的普遍保证；证据不足保持 trial。

安全反例立即 suspend；明确相关的重复质量失败触发复查。用户说“不再按这个做”立即停止推荐。内容变化创建新版本并重新试用，不能继承旧版全部成功计数。回滚 Learner 不回滚用户纠正、删除或授权撤销。

## 7. 采用与收益

- Exposure：实际送进某次模型请求，编译但未发送不算。
- Adoption：计划步骤/行动参数实际使用了该版本；模型自称仅为 claimed。
- Outcome：该任务按标准的结果，包含未知。
- Benefit：与匹配基线或用户明确比较有关的收益，无法归因保持 unknown。

不把同一记忆被多次检索当作多次成功，不把一次任务的多轮重放当作独立样本。线上不能为了对照重复产生真实副作用；对照在沙箱、只读任务或明确获准试用中完成。

## 8. 学习审计与评估

每个版本能回答来源、为何接受、适用范围、在哪些任务被采用、发现过哪些反例、如何撤回。评估集按完整任务/用户情境隔离，生成集与保留集不能共享同一事件变体。

离线比较：无学习、只有显式记忆、固定检索、完整学习；同模型、同输入输出预算、相同任务与验证器。报告完成率、错误复发、重复解释、成本、未知归因及安全失败，不能只给一个模型裁判总分。验收 L01—L08。
