# 主动协作与注意力管理

状态：SA1 设计。目标是减少用户等待与协调负担，主动消息数量不是成功指标。

## 1. 主动性的来源

允许的来源包括已确认 Goal/Commitment、用户开启的 Source 规则、当前任务变化、证据冲突/过期、已经登记的 OpenQuestion。用户可以授权“看到这类变化，先帮我准备”，无需每次逐条询问；授权必须有可解释的范围、动作、费用、期限和撤销入口。

普通闲聊和外部人发来的要求不自动成为用户长期目标。没有目标或明确持续规则时，不扫描所有资料“找事情做”。自发建议是 Opportunity，不是已接受 Task。

## 2. Opportunity 与成熟

候选字段：scope、audience、goal/commitmentRef、triggerRefs、evidenceRefs、whatChanged、whyNow、actionProposal、expectedBenefit、uncertainties、estimatedCost、expiry、topicKey、reevaluateOn、lastEvaluatedSourceVersions。

“成熟”表示有足够证据、能采取具体动作、时机有价值；不使用一个综合置信度代替这三个判断。证据不足可等待指定信号；长期无新证据或目标失效则过期关闭。

evidenceDedupKey 防重复摄取，topicKey 合并同一事项的多次变化。新证据更新旧候选；只有新的实际影响或时间窗口才重新决定是否打扰用户。

## 3. 三个独立判断

1. **价值**：与哪个目标相关、信息是否新鲜、是否可行动、现在处理有什么收益。
2. **执行资格**：是否有读取/模型/草稿/写入许可，预算和资源是否允许。
3. **沟通时机**：用户静音、频率、重复、当前对话和事项紧急度是否允许通知。

通知静音不自动禁止已经获准的后台准备。后台计算和通知分别计量；某类禁止读取则既不准备也不生成包含该内容的提醒。

## 4. 决定与结果

| 决定 | 条件 | 后续 |
|---|---|---|
| retain | 可能有用但缺证据，有明确等待条件 | 保存候选与重新评估触发，不调用工具 |
| dismiss | 无关、重复、过期、已处理、缺少价值 | 关闭并记固定原因 |
| prepare | 有价值，获准读取/分析/隔离草稿足够 | 创建有预算 Task，准备成果可撤销 |
| notify | 有新价值且需用户知道或选择，时机允许 | 生成受控 Delivery |
| execute | 直接请求或有效持续 Grant 覆盖动作 | 经普通 Task/Action 路径执行 |

通知本身也需要来源渠道的发送许可。打开通知或不回应都不扩大执行权。prepare 不包括发送邮件、评论 PR、购买、修改远端对象；这些属于明确外部动作。

## 5. 默认负担预算

默认非紧急主动通知每天最多 3 条，同 topic 24 小时冷却，quiet hours 为用户时区 22:00—08:00。参数可由用户调整。紧急例外只来自用户明确配置的承诺类别和时间窗口，模型不能自行把普通事项升级以绕过静音。

多个低优先级变化合成摘要；有正在进行的同主题对话时将有用结果附在该对话的合适边界，不抢占每个用户输入。发一串“要不要我做……”不算主动价值，已有明确许可的准备应在后台完成。

来源风暴按 source/topic 合并，有界队列与每来源配额；控制命令、撤销和关键终态不能被丢弃。来源长期异常暂停该来源并报告一次具体问题，不反复通知相同故障。

## 6. 反馈

`handled` 关闭事项；`snooze` 保存具体唤醒时间；`irrelevant` 影响同范围候选排序；`disable` 是立即生效的强规则。忽略只记录 no-response。点击、回复轮数和停留时间不能直接作为收益或授权。

用户修改目标后撤销失配候选、准备作业与调度。不能换文案重新推送已关闭事项；用户明确重新开启才允许恢复同类规则。

## 7. 提前准备与主动学习的协作

Opportunity 可以发现缺少可靠依据并创建 OpenQuestion。Learning 只能在已有许可内检索或实验，返回证据后再评估候选。没有新证据就不循环调用两个 Agent 互相提高置信度。

准备成果保存适用目标/来源版本，交付前核对是否仍有效。目标已取消、资料被纠正或过期时，标明失效并停止交付；已产生的成本保留，不伪装从未执行。

## 8. 时间与恢复

调度保存时区、原始本地时间规则、解析后的 UTC、规则版本。夏令时重复/不存在时刻采用已声明策略；不能只存一个不带时区的 cron 字符串。

睡眠/停机恢复只补仍有价值的事项，按 topic 合并；不把错过的所有提醒一次发完。每日预算按用户时区计算，切换时区不重新发放已消费额度。授权到期或 Source 撤销使等待和准备立即停止新执行。

## 9. 价值验收

准备成果是否被采用、是否减少用户工作、遗漏了多少有价值窗口、多少通知无用，分别测量。使用真实标注的应行动/应静默时间线，与固定规则和完全静默比较；不能用纯静默取得虚假高准确率。具体 A01—A08 见[验收](acceptance.md)。
