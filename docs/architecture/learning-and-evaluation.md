# 学习、经验演进与评估

状态：design-v2。P1 收集结果与使用记录；P2 启用自动归纳和做法试用。本设计所称学习是记忆/策略选择与程序性知识的改善，不更新基础模型权重。

## 学习流水线

Outcome committed → 幂等学习作业 → 选择有新信息的 Episode → 生成候选 → 核心检查证据/冲突/范围 → 试用/审阅 → 发布新版本或拒绝。

作业键为 taskAttempt + outcomeRevision + learnerVersion；只消费持久事件。不按每个 Token 做反思。默认任务后最多一次归纳调用、每日最多十次后台归纳；无新证据不运行。超额持久排队，用户交互优先。预算为可配置首版初值。

## 学什么与不学什么

| 材料 | 可形成 | 不可直接形成 |
|---|---|---|
| 用户明确偏好/纠正 | asserted Claim、新 Goal revision | 更大权限 |
| 工具可验证状态 | 有时间范围的 verified Claim | 永久世界事实 |
| 一次成功/失败任务 | Episode、Hypothesis、ProcedureCandidate | 已验证通用技能 |
| 多次可比较任务 | 适用边界、失败条件、选择偏好 | 未经评估的跨 Workspace 推广 |
| 用户忽略/点击提醒 | 有限制的交互反馈 | 用户满意/授权/目标成功 |

学习内容必须能指向原始证据，自动摘要/反思互相引用不能构成独立支持。撤销、纠正与遗忘传播至 Episode 摘要、Procedure、检索和计划；依赖不足则 suspend/review_required，不继续使用旧证据。

## Procedure 合同与状态

Procedure 是版本化、声明式做法：任务类别、前置条件、资源需求、步骤、检查点、验证器、禁止/失败条件、预期收益、证据与版本来源。首版不存任意可执行代码或修改系统 Prompt 的脚本。

状态：CANDIDATE → TRIAL → ACTIVE → SUSPENDED / RETIRED；内容修改创建新版本并回到 TRIAL。active 只表示在明确范围可推荐，不提供工具授权。

首版晋升规则（工程门槛，不是统计学普遍有效保证）：

1. 至少 5 个独立 taskAttempt，来自至少 3 个不同任务；重复 replay、同一次结果修订不增加样本数。
2. 至少 4 个结果可验证；必须记录全部失败/取消/未知，不能挑选成功案例。未知不进入成功分母，也不得隐去其数量。
3. 至少 3 次 adopted_verified；被注入或模型自称使用不能替代。
4. 至少一个未用于生成该做法的保留场景，通过其验收；可比基线下质量不下降且存在预先声明的收益（质量、步骤、时间或成本）。
5. 无安全违规、无未处理严重反例；知识范围与试验范围一致。主观做法需用户确认其有用。
6. 核心规则审核与学习审阅可解释，保留 previousActiveVersion 以回滚。

安全反例立即 suspend；连续 2 次与该做法明确相关的验证失败也 suspend 并复查。无采用证据的任务失败仅记相关未知，不武断归因。30 天未使用只降检索优先级，不删除证据；过期前提立即停止适用。参数可配置但不可低于安全红线。

## 归因与收益

MemoryUse 的 exposure/adoption/outcome/benefit 按[认知合同](cognitive-loop.md)记录。可验证采用例：计划步骤引用 procedureVersion，执行轨迹满足其中检查步骤；约束实际进入参数且检查器确认。无法从可观测轨迹证明时仅 claimed/unknown。

收益优先用相同任务、相同 Runtime/模型/预算的配对离线对照。在线任务不为了试验重复产生副作用；只在沙箱、只读任务或用户明确允许的试用内比较。用户说“这次更好”记录为 user_reported，不伪装为因果结论。系统只能报告证据支持的改善范围。

## 抗漂移与污染

任务执行中的网页/工具内容视为数据，不能成为学习器的高优先指令。候选抽取 Prompt 固定版本，输出过 schema 再验原证据。来源跨度、隐私、实体和有效时间冲突时拒绝自动合并。摘要归并不删除反例或扩大 scope；可从证据重算。

做法生成集、调参集、保留集按完整任务/用户情境划分，禁止同一任务变体跨集合泄漏。每轮版本保留学习前快照与评估配置，可停用新 learner 回到旧版本；已明确纠正/遗忘的数据不能随回滚复活。

## 评估设计

四个同模型同预算基线：无长期记忆、可容纳的完整历史、固定摘要+简单检索、知微治理记忆。增加“关闭学习但保留记忆”的消融，区分检索帮助与经验学习帮助。完整历史超窗口必须报告截断策略与成本，不能把不同预算结果作公平比较。

评估分别测：证据支持正确率、跨会话任务完成、时间/知识更新、拒答合理性、纠错与遗忘生效、收益、延迟/token/费用、主动噪声和遗漏。每项给样本数/未知数/分布，模型裁判只是辅助，与确定性验证/盲评分开。具体发布门见[验收标准](../planning/acceptance-criteria.md)。

## 研究依据与边界

这些资料提供方向，不证明知微已经达到论文结果，未直接移植任何系统：

- [LongMemEval](https://arxiv.org/abs/2410.10813)分别评估提取、跨会话推理、时间推理、知识更新和拒答；据此保留多维记忆评估，另增加行动任务与治理场景。
- [Reflexion](https://arxiv.org/abs/2303.11366)研究将任务反馈转为语言经验，用于后续尝试；知微采用显式反馈/经历的方向，但不把自我反思当结果验证。
- [A-MEM](https://arxiv.org/abs/2502.12110)研究动态组织与链接记忆；知微允许派生链接演进，同时保持原始证据与生命周期可治理。
- [Mem0](https://arxiv.org/abs/2504.19413)研究抽取、整合与检索的效率；知微把其视为待本地对照的设计启发，不引用不同设置的性能数字作为产品承诺。
