# ADR 0020：显式记忆服务与可重建全文检索

- 状态：Accepted
- 有限设计审查：[PR119 独立设计记录](https://github.com/ntygod/zhiwei-next/pull/119#issuecomment-6105607704)绑定原提案 SHA256 `43ecbbed7b1eac7bf68998b299fd1b6470d32480a7e53494ee6501d2e5f88c82`；仅接受此合成设计，不批准当前或未来实现 HEAD。
- 日期：2026-10-11
- 工作项：[#118](https://github.com/ntygod/zhiwei-next/issues/118)，P1-05 / [PR120](https://github.com/ntygod/zhiwei-next/pull/120)
- 被取代关系：细化 ADR0017/0018 的记忆接口与检索实现；保留原领域、隐私、控制日志、Runtime 和验收边界。

## 背景

P1-01/02/04 已提供纯认知转换、不可变证据、正文治理和持久配对 API。P1-05 需要把这些组件组合为可纠正的记忆流程，不能由录入接口直接伪造 Claim 来源，也不能从新索引恢复已遗忘的正文。

## 决策

显式输入先产生由配对应用拥有的 user-direct Observation。remember/correct 由 cognition-core 构造 PENDING/ACCEPTED Candidate 与 Claim；memory-store 在同一事务提交证据、精确快照、版本指针、失效、epoch 和回执。纠正保留旧版本；争议只改变原版本状态，反证保存在新的命令 Observation，原 Claim 内容和证据不被改写。未证明的自动候选仍不参与本接口。

检索先建立同一 SQLite snapshot，按 Workspace/具体 Scope、当前隐私、可用来源、生命周期、validAt/knownAt 和 kind 选择精确版本，再对合格 Claim 正文排序。knownAt 重建当时已知的版本/状态；当前遗忘、来源不可用和权限收紧始终生效。历史结果显式标记，不能冒充当前约束。v1 Workspace 数据接口不接受 global 写入或跨 Workspace 查询。

首版使用请求内 SQLite FTS5 trigram 派生表，没有独立持久索引副本；每次从已合格结构化真源重建。少于三个 Unicode 字符的短查询使用显式声明的同 Scope 字面扫描，完整查询作为字面短语，不把 FTS 操作符当命令。结果上限沿用已有 v1 的 50 条。此选择只证明合成中文样例，不声明大规模性能或中文分词产品验收；之后若需要持久索引，以现有实测任务决定。

固定前向迁移 0004 保存正文受保护的命令回执和必要内容依赖。SQL 投影仅保留受控身份、版本和水位；命令文本、原因及用于幂等比较的语义留在受管正文。回执正文不可用时拒绝重新执行。原 0001—0003 不变；原 v1/v2/v3 独立读取入口仍按精确版本拒绝 schema4。

遗忘先提交命令准备记录，再向既有独立控制日志写入最小精确版本意图，完成对账后持久提交回执。两处不是一个事务，失败保持 recovery_required；重开按原日志恢复，使用准备时保存的 operationId/时间继续，不能重新保存遗忘的正文。命令副本和 Candidate 正文参与同一失效依赖闭包。这里只提供逻辑遗忘，不声称完成全介质物理清除。

## 备选方案与后果

持久 FTS 索引可减少重复构建，但增加政策收紧、清除和水位一致性的实现面；在当前合成纵向切片不采用。只用原始对话全文会混淆证据与事实，不采用。向量/混合检索仍按 X2-01 的实测条件推进；不新增通用 Provider 或模型抽取框架。

请求内索引的代价是每次构建，不承诺规模性能。解释只返回精确版本、当前可用来源、最新 50 个版本的最小元数据和依赖，不在正文失效后用占位内容制造可用 Claim。

## 验证、回滚与启用

正常合成输入/记忆/纠正/争议/遗忘/重开、双时间、Scope/隐私先过滤、回执去重与旧 revision 拒绝用真实临时 SQLite 验证；复用原完整 check 和当前 HEAD 独立 R3。仅合成临时 Daemon/配对 API 接线，普通启动入口保持诊断用途。Z04/Z06/Z13 产品验收与 Windows 支持验证仍 not_run，旧受限安全实验不执行。

停用记忆入口/注入即可撤回消费者；保留结构化真源、版本和控制日志，索引无需恢复。schema4 不向后降级；代码回退通过新的受审 PR，已升级安装须前向修复或保持关闭，禁止用旧库回滚遗忘。没有新的真实模型、账户、个人数据、外发或部署权限。
