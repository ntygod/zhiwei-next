# ADR 0008：会话记录与模型输入重建的边界

- 状态：Accepted
- 日期：2026-10-08
- 计划决策：D-01；关联 D-04/D-05/D-09
- 被取代关系：不取代 ADR 0005/0006，不扩展 NormalizedRuntimeEvent v1

## 背景

事件回放、模型输入重建和相同输出复现是不同结果。现有 Runtime v1 和 Ledger 只保存已观察的规范化事实，不具有正式 SessionContract、模型请求 Step、最终输入采集器或内容保留政策。Message Snapshot 不能证明后续 Pi/Provider 变换。

## 有限决策文本

选择获准完整正文或可解析的不可变内容引用，并保存有序组成、来源边界及摘要。hash/摘要只证明身份，不能重建正文；缺引用、摘要漂移、缺失或乱序必须失败，不得猜测或静默修复。完整性只对实际观测且保存完备的边界成立；未观测的 Runtime/Provider 变换明确标未证明，不声称真实远端完整输入或确定性输出复现。

合同/配置 revision 不可变。请求 pin 当时有效的 revision 和摘要，历史解释不能用当前配置倒推。新配置完整验证后才发布；失败不发布半应用 revision，旧在途请求不改写。此为方向选择，精确正式字段、owner 并发、持久化原子性由 D-09/M0-2/3 决定；本项不向 v1 payload 偷加字段。

M0 只记录无记忆会话。M2-3/4 才增加 Claim 版本、认知水位、Compiler revision、胶囊及选择依据。不得保存模型原始思维链；真实正文保存/删除/备份和失效策略由 D-04/G-2 决定。D-05 单独决定摄取确认与投影水位：Ledger 提交、投影完成、模型成功不能复用一个 accepted 状态。

## 备选方案

- 保存原始 Pi payload：违反中立投影及原始思维链限制，不选。
- 只保存 hash/摘要：无法重建内容，不选作完整方案。
- 获准正文/不可变可解析引用：选择，同时明确内容不可用结果。
- M0 提前注入完整记忆胶囊：违反 M0/M2 分工，不选。

## 证据与审查

[G-1c 合成输入实验](../spikes/session-reconstruction/README.md)覆盖许可正文/引用、摘要与顺序、缺失/漂移拒绝、未观测变换、配置失败发布及历史 revision。组装器的 synthetic-assembly-output 是内存合成输出，绝非真实 Pi/Provider 请求捕获；SHA-256 是一致性检查，不是来源认证。

[当前执行决议 D-01](../planning/current-decisions.md#d-01)记录有限范围和真实实验身份。Evidence Ready 只表示证据准备，不构成 ADR 接受；ADR 接受需新的逐项正式决策审查，实际状态以上方状态行和当前执行投影为准。PR #79 的实验批准不接受本决策；当前/最终 HEAD 的审查仍由现行治理负责。

## 后果、限制与回滚

记录成本和内容保留责任增加，但不能把事件存在误说成内容可重建。M0-3 的正式合同/写读能力、M0-4/8 的真实 Runtime/E0-09 证据、D-04/G-2 保留授权、D-09 owner/并发及 D-05 摄取投影各有独立前置，不要求这些未来产品交付先于本有限技术选择，却也不由本决策替它们验收。

本轮不改 Schema、迁移、协议、Session 产品 API 或运行配置。不自动放行工作包/阶段。撤回文档和执行状态资料即可；未来已保存会话的恢复/迁移须另有证据，不能由本提案授权删除。
