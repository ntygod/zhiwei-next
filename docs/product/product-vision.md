# 知微 2.0 产品愿景

## 一句话定位

知微是一个**本地优先、记忆可治理、主动但不过界、模型与 Agent Runtime 可替换的个人认知 Agent**。

## 目标用户

第一阶段服务长期处理复杂项目的开发者、研究者、创作者和高强度知识工作者。他们面临的核心问题不是“缺少一个聊天框”，而是：

- 每次新会话都要重新解释背景；
- 旧决定、失败尝试和项目约束散落在多个工具；
- Agent 会记错、记多、记得无法纠正；
- 自动化缺少长期边界、责任和可审计性；
- 更换模型或 Agent 后，个人连续性随平台消失。

## 产品承诺

### 记得对

长期记忆不是聊天记录的向量化副本。可使用的认知必须带证据、作用域、版本和生命周期。

### 改得掉

用户纠正后，旧结论立即停止进入 Agent 上下文；历史仍可追溯，但不会与新结论竞争召回。

### 说得清

每条记忆、主动建议和授权行动都能解释来源、选择原因、影响范围和修改方式。

### 想得早

知微能够发现截止时间、长期未推进事项、约束冲突和准备机会，但不会为了显得主动而制造提醒。

### 不过界

主动发现与外部执行严格分离。执行必须经过具体的资源、工具、时间、风险和预算授权。

### 属于用户

数据默认保存在本地，能够完整查看、导出、删除并跨 Runtime 使用。

## 最终产品表面

- 桌面工作台：今日、工作空间、记忆、关注、委托、活动；
- Pi 原生 Package：为 Pi 用户提供知微认知能力；
- 本地 CLI：诊断、查询、回放和自动化；
- 移动伴侣：提醒、审批和结果查看；
- 跨 Agent Adapter：Codex、Claude 和其他 Runtime 共享同一认知内核。

## 不成为谁

知微不是另一个通用 Agent Loop、工作流 DAG 平台、多 Agent 蜂群、插件市场或模型路由平台。Pi 负责执行，知微负责连续性、治理、主动性和边界。

## 北极星指标

**认知连续成功率**：在用户没有重复说明背景的情况下，知微能否使用正确的历史上下文帮助长期任务成功。
