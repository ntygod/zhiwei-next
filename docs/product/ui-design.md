# 交互设计：围绕合作任务组织界面

状态：design-v2 目标。P1 有可用界面，P4 完整桌面；原[原型](../design/prototype/README.md)保留为历史交流，不决定新导航。

## 信息结构

左侧一级导航为「今天」「项目」「记忆」，底部「设置」。项目工作台中间是对话与产物，右侧可收起的任务/目标/依据面板。进行中与待审批数在导航旁。审计在详情与设置内，不占一级导航。用户离开对话仍能找到任务和产物。

```text
┌ 今天 / 项目 / 记忆 ┬ 当前项目 · 目标摘要           ┬ 本次工作 ┐
│ 项目列表          │ 对话 / 产物预览               │ 任务状态 │
│                  │                              │ 完成条件 │
│ 进行中 1 待审批 0 │                              │ 待核实项 │
│ 设置             │ 输入框 · 附件 · 本轮范围      │ 依据入口 │
└──────────────────┴──────────────────────────────┴──────────┘
```

P1 选择 React + TypeScript + Vite 的本地 Web UI；P4 Electron 壳承载相同 UI。UI 只调用 Daemon API。Electron 主进程只负责窗口、通知、Daemon 生命周期、升级与 OS 凭据桥；renderer 禁用 Node 集成，启用隔离。新依赖版本在实施任务中精确锁定与验证，本次不安装。

## 页面合同

| 页面 | 默认内容 | 主操作 | 详情 |
|---|---|---|---|
| 今天 | 继续上次工作、待决定事项、今日承诺 | 继续/处理/稍后 | 为什么现在、关闭类别 |
| 项目 | 目标、任务、对话、产物 | 发起/继续、调整目标 | 依据、状态历史 |
| 任务 | 状态、进度、完成标准、产物 | 停止、补充输入、确认结果 | 失败原因、重试、授权 |
| 记忆 | 可读认知与做法，按项目/全局筛选 | 搜索、纠正、遗忘、禁用 | 来源、版本、影响 |
| 设置 | 模型、目录、连接器、隐私、通知、备份 | 配置、撤销、导出/恢复 | 版本、脱敏诊断 |

普通界面用“项目决定”“待核实”“最近学到的做法”等语言，不要求用户学习 Claim、watermark 或 PolicyGrant。稳定 ID/版本只在排错详情显示。

## 核心交互

1. **继续**：展示上次任务与状态；有歧义时最多三个候选。没有证据时说明缺失，不编造进度。
2. **纠正**：支持回答旁、记忆详情和自然语言入口。展示新内容/作用域及影响；提交后旧版本立即失效，不能等待索引重建。
3. **遗忘**：区分停止使用与清除保留内容；分别显示逻辑失效、当前副本清除、离线备份残留。不得显示虚假的“全部删除”。
4. **结果**：主结论、产物、验证证据、未完成项顺序固定。“符合要求/需要修改”是反馈；未点击不等于成功，验证不足显示待核验。
5. **学习**：结果下附轻量建议，普通归纳按规则形成可撤销候选；长期偏好变化、跨范围推广须确认。学习不阻塞下一任务。
6. **审批**：显示动作、对象、内容/差异、外发数据、有效期、次数/成本上限。按钮为仅本次允许、在所示范围内允许、拒绝；无模糊全局信任。
7. **进度**：消费结构化订阅事件；无总量时显示不确定进度，不虚构百分比，不调用模型查进度。对应 owner-input #44。
8. **主动**：每项含发生了什么、关联目标、为何现在、准备成果及建议。支持稍后、已处理、不相关、关闭此类；关闭后不换文案重发。

## 全状态体验

| 状态 | 显示 | 恢复 |
|---|---|---|
| 正常 | 持久提交后显示已保存 | 当前任务操作 |
| 空 | 一句解释，一个相关行动 | 建项目/加材料 |
| 加载 | 保留旧内容与时间，临时流式文本单独标记 | 可取消 |
| 断线 | 最后确认状态、断线时间；不假定任务成败 | cursor 重连 |
| 错误 | 安全摘要与可复制诊断 ID | 重试/设置/脱敏导出 |
| 权限 | 精确指出受阻范围 | 缩小任务/授权 |
| 模型不可用 | 搜索、纠错、导出仍可用，生成暂停 | 换获准模型/稍后 |
| 索引滞后 | 核心过滤仍执行 | 安全真源查询/明确暂不可用 |
| 副作用未知 | 待核对，不提供普通重复发送按钮 | 查回执/人工核对 |
| 冲突 | 并列版本、来源、有效时间 | 选择/补证据 |

## 视觉与可访问性

中文优先、系统字体、清晰层级，首页不堆工程表格。全部核心路径可键盘完成，焦点可见，弹层关闭返回触发点。错误/状态不只用颜色；任务状态低频 aria-live，Token 不逐字朗读。支持减少动画、高对比、200% 缩放；窄窗口右栏变抽屉。

P1 对正常/空/加载/错误/权限/降级做截图和键盘验收；P4 增加托盘、通知、冷启动、恢复与读屏。文档一致不能代替实际使用体验。
