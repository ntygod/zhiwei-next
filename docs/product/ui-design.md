# UI 设计总纲：Quiet Intelligence

## 设计方向

> Quiet Intelligence｜安静的智能

界面应当沉静、可信、结构化，不像聊天机器人，也不应像复杂的 Agent 管理后台。

## 顶级信息架构

```text
今日
工作空间
记忆
关注
委托
活动
```

底部常驻本地运行状态与设置。会话属于工作空间，不作为顶级导航。

## 核心决策

1. 首页回答“今天什么值得推进”，不是展示空白聊天框。
2. Workspace 是首要上下文和隔离边界。
3. 本轮使用的记忆必须有轻量可见入口。
4. 展示行动、依据、工具和结果，不展示模型原始思维链。
5. Attention 只提出建议；执行前必须形成 Delegation Contract。
6. 权限确认必须说明 Agent、动作、资源、工具、时间和预算。
7. 复杂来源、版本和审计信息渐进披露。
8. 本地 Daemon、Runtime、模型和数据外发状态持续可见。

## 关键界面

- 今日首页；
- 工作空间概览；
- Agent 会话与依据栏；
- 权限确认卡片；
- 任务完成后的学习审阅；
- 当前认知、时间线、待确认、冲突与遗忘；
- 关注事项详情；
- 委托草案和运行中委托。

## 视觉语言

- 温和灰白背景、深灰绿正文、克制品牌绿；
- 普通卡片使用边框和留白，不堆阴影；
- 不使用紫色 AI 渐变、机器人头像和持续闪烁；
- 状态不能只靠颜色表达；
- 运行状态用“读取文件、等待确认、运行测试”等明确动作描述。
